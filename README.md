# TRPGシナリオ コピー支援

TRPGシナリオ本文から、必要な行をクリックまたはドラッグでコピーする静的Webアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「入力・設定」で本文を直接入力するか、UTF-8の `.txt` ファイルを読み込みます。
3. 必要に応じて「置換設定（ココフォリア等の変数）」から置換ルールを追加します。
4. 「コピー」タブで行をクリックすると単行コピー、行をドラッグすると連続行コピーできます。

## 公開

依存関係やビルド手順はありません。
GitHub Pagesでは、リポジトリ直下を公開対象にするとそのまま動作します。

## コピー画面だけの改行編集

- 本文の任意位置を右クリックし「ここで改行」で行を分割。
- 行間の細い領域をダブルクリックすると前後を結合（空白は追加しない）。追加した改行も同じ操作で削除できる。
- 編集後の表示行をクリックして1行、ドラッグして複数行をコピー。置換ハイライトのクリックは従来どおり個別除外を切り替える。
- 元テキストと置換ルールは変更しない。本文が変わると改行編集をリセットする。同じ本文への入力方式切替では保持する（CRLF/CRはLFとして比較）。
- 改行編集は一時状態。設定JSONの「本文固有状態（個別除外・改行編集）を含める」で保存できる。本文のフィンガープリントが一致する置き換え読み込みで復元する。追加読み込みでは復元しない。

JSON v1 の `individualState` に任意項目を追加：

```json
{
  "insertedBreaks": [{ "lineId": "line-0", "offset": 2 }],
  "removedLineBreaks": ["line-1"]
}
```

`lineId` は解析時の元行ID、`offset` はその行の**置換後テキストのUTF-16オフセット**。削除対象は指定元行の直後の境界。置換変更・個別除外切替では数値位置を保持し、現在の置換結果の長さを超える位置は適用しない。置換ルールだけのJSONには含まれず、旧v1 JSONも読み込める。localStorageは従来どおり置換設定だけを保持する。

## テスト

```sh
node --test
```

`lineBreaks.test.js` は改行の追加・削除・複合操作・境界位置・ハイライト属性の保持・コピーイベント・本文リセット・JSON互換性を検証する。
